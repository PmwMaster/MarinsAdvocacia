# MARINS Advocacia Criminal - Landing Page Premium

Uma landing page de alta conversão, desenvolvida sob medida para um escritório de advocacia criminal focado em estratégia e resultados. O design utiliza uma estética "Boutique" (Premium/Luxury) com as cores Navy (Azul Escuro) e Gold (Dourado), transmitindo extrema autoridade, sigilo e exclusividade.

## 🎯 Objetivo do Projeto
Atrair leads qualificados e oferecer um canal rápido e seguro para urgências criminais (plantão 24h). O foco total da arquitetura de informação é a conversão, utilizando funis de contato rápidos e gatilhos mentais de autoridade.

## 🚀 Funcionalidades e Diferenciais
- **Design de Alta Performance:** Layout responsivo, focado na leitura ágil e sem distrações.
- **Animações Cinematográficas:** Implementação de micro-interações como `magnetic buttons`, efeito `shimmer`, `tilt 3D`, barras de progresso de scroll e revelação progressiva (`fadeInUp`).
- **Funil Direto para WhatsApp:** Formulário de triagem funcional que formata os dados do lead (Nome, Telefone, Área de Interesse) e envia diretamente para o WhatsApp do advogado.
- **SEO e Compartilhamento Otimizados:** Meta Tags configuradas (Open Graph) para exibição perfeita de thumbnail e descrições ao compartilhar o link via WhatsApp ou redes sociais.

## 🛠️ Tecnologias Utilizadas
O projeto foi construído priorizando a velocidade e a manutenibilidade, sem depender de frameworks pesados:
- **HTML5** (Semântico e acessível)
- **CSS3 Vanilla** (Uso extensivo de variáveis `:root`, Flexbox, CSS Grid e Keyframes personalizados)
- **JavaScript Vanilla** (Interação de botões, interceptação de formulários, IntersectionObserver para contadores)
- **Bibliotecas Externas:**
  - [AOS (Animate On Scroll)](https://michalsnik.github.io/aos/) - Para animações baseadas no scroll.
  - [Swiper JS](https://swiperjs.com/) - Para o carrossel tátil da seção "A Estratégia".
  - [FontAwesome](https://fontawesome.com/) - Para a iconografia padrão.
  - [Google Fonts](https://fonts.google.com/) - Tipografia premium (`Playfair Display` para títulos e `Montserrat` para corpo).
